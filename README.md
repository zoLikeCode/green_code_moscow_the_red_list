### Описание:

**Красная книга Москвы** - это *электронный ресурс* для сотрудников департамента природопользования и жителей Москвы, разработанный *для повышения осведомленности о редких видах и мониторинга их численности*. Проект создан в рамках хакатона [«Зелёный код Москвы»](https://green-code-moscow.ru/) для департамента природопользования города Москвы.

---

### Установка и запуск проекта:

1. Для запуска проекта, сначала нужно клонировать репозиторий:
```bash
git clone https://github.com/zoLikeCode/green_code_moscow_the_red_list.git
```
2. Находясь в основной папке проекта, прописать команды, чтобы запустить проект локально с помощью *Docker*:
```bash
docker-compose build --no-cache
docker-compose up
```

### Основной функционал проекта:

**1. Путеводитель (для всех пользователей):**
- Просмотр подробной информации о краснокнижных обитателях московских парков.
- Отображение ареалов обитания животных на карте.
- Отправка сообщений о найденных животных или растениях, включая фотографии и координаты.
- Взаимодействие с виртуальным помощником «Рябчик» для навигации по сайту.

**2. Мониторинг (для сотрудников департамента природопользования):**
- Ведение учета численности животных.
- Корректировка границ ареалов обитания на карте.
- Просмотр видов, обитающих на конкретных кадастровых участках.
- Обработка поступивших сообщений от жителей, включая просмотр загруженных фотографий и данных.
- Работа с кадастровыми номерами участков на основе координат.

### Заключение:

**Красная книга Москвы** — это уникальный инструмент, объединяющий образовательную, экологическую и аналитическую составляющие. Он делает данные о редких видах доступными как для широкой аудитории, так и для специалистов, помогая сохранять биологическое разнообразие в мегаполисе. Благодаря удобному интерфейсу, мотивационной системе для пользователей и функционалу мониторинга для специалистов, проект закрывает разрыв между горожанами и природопользованием.

**Идеи для масштабируемости:**
1. Геймификация: разработка системы наград и достижений за активность на платформе.
2. Внедрение уже накопленной базы данных департамента и интеграция с планами застройки.
3. Расширение функционала: связь с автором обращения, параметров отображения на карте, создание персонального фотоальбома, добавление статистики.
